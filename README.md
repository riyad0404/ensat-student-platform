# Docentra – ENSA Tangier Student Collaboration Platform

Docentra is a collaborative academic platform developed by a team of engineering students at ENSA Tangier.  
The objective is to centralize academic resources, improve communication between students, and provide structured access to documents, discussions, and guidance.

The project was carried out using an Agile / Scrum methodology.

---

## Features

- Secure authentication system
- User profile management
- Posts and comments system
- Real-time messaging (1-to-1 and groups)
- Document sharing and structured library
- Bookmark system
- Notification system
- Initial chatbot integration

---

## Technical Stack

### Backend
- Node.js
- Express.js
- PostgreSQL
- REST APIs
- WebSocket / Socket.IO

### Frontend
- React

---

## Architecture

- REST API communication between frontend and backend
- Role-based access control
- Real-time features using WebSocket
- PostgreSQL relational database
